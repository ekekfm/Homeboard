# 홈보드 (PWA)

일정, 사업, 자산, 취미, 메모, 뉴스를 한 화면에서 보는 개인 대시보드입니다. GitHub Pages에 올리면 폰 홈 화면에 앱처럼 설치할 수 있습니다.

## 올리는 방법
1. GitHub에서 새 저장소를 만듭니다. (무료 계정은 Public이어야 Pages를 쓸 수 있습니다)
2. 이 폴더의 파일을 **전부** 저장소에 올립니다. `.github` 폴더와 `.nojekyll` 파일은 숨김 파일이니 빠지지 않게 확인하세요.
3. 저장소 Settings > Pages > Source를 "Deploy from a branch", Branch를 `main` / `(root)`로 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소 이름>/` 으로 접속합니다.
5. Actions 탭 > "아침 뉴스 갱신" > Run workflow 를 한 번 눌러 뉴스가 채워지는지 확인합니다. 이후에는 매일 오전 6시 47분쯤 자동 실행됩니다.

## 폰에 설치
- 아이폰: Safari로 접속 > 공유 > 홈 화면에 추가
- 안드로이드: Chrome으로 접속 > 메뉴 > 홈 화면에 추가(앱 설치)

## 알아둘 점
- 기록은 각 기기의 브라우저 안에만 저장됩니다. 폰과 PC는 자동으로 맞춰지지 않으며, 홈 > 설정과 백업에서 백업 파일로 옮길 수 있습니다.
- 저장소가 Public이어도 기록한 내용은 올라가지 않습니다. 공개되는 것은 앱 코드와 뉴스 헤드라인뿐입니다.
- 날씨는 Open-Meteo, 뉴스는 구글 뉴스 헤드라인(제목과 링크)을 사용합니다.
- 화면을 고친 뒤에는 `sw.js` 의 `homeboard-v1` 숫자를 올리면 설치된 앱이 새 화면으로 바뀝니다.

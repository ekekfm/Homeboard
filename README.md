# 업무 보드 (PWA)

일정, 할 일, 가계부, 메모, 뉴스를 한 화면에서 보는 개인 업무 보드입니다. Google 계정으로 로그인하면 PC와 폰에서 같은 기록을 봅니다.
GitHub Pages(ekekfm/Homeboard)에 올려서 쓰며, 동기화는 Firebase 무료(Spark) 플랜만 씁니다.

---

## 2단계 올리기: 업무·메모·일정 (2026-11-21)

1. **보안 규칙 다시 등록**: Firebase 콘솔 → Firestore → 규칙 탭에 새 `firestore.rules` 내용을 통째로 붙여 넣고 **게시**. (업무·작업 시간 저장 칸이 추가됐습니다. 안 하면 업무가 다른 기기로 넘어가지 않고 "서버가 요청을 거부했습니다"가 뜹니다.)
2. ZIP 안의 파일을 전부 Homeboard 저장소에 올립니다(`css`, `js` 폴더 포함).
3. 업무 탭 → **기존 업무 29개 가져오기**는 **한 기기에서만** 누릅니다. 다른 기기에는 동기화로 넘어갑니다.

새로 생긴 것
- **업무 탭**: 분류·상태(예정·진행 중·완료·보류), 다음 행동, 체크리스트(진행률 자동), 선행 업무(안 끝났으면 "차단됨" 표시, 상태는 바꾸지 않음), 업무 메모, 연결된 메모
- **이번 주 시간**: 목표 20시간(분야별 15 + 유동 5) 대비 실제 작업 시간, 남은 시간, 달성률, 분야별 막대, 초과 경고
- **메모**: 태그, 맨 위 고정, 업무 연결, 휴지통(30일 보관 후 정리)
- **일정**: 하루 종일, 반복(매주·매월·매년, 끝나는 날 선택)

## 1단계 설치: 로그인과 동기화 (처음 한 번)

### ① 지금 기록 백업
업무 보드(지금 홈보드)를 열고 **홈 → 설정과 백업 → 백업 파일 저장**을 누릅니다. 폰과 PC 기록이 다르면 두 기기에서 각각 받아 두세요.

### ② 보안 규칙 등록 (Firebase 콘솔, 2분)
1. console.firebase.google.com → work-board 프로젝트 → 왼쪽 **Firestore** → 위쪽 **규칙** 탭
2. 편집창의 내용을 모두 지우고, 이 폴더의 `firestore.rules` 파일 내용을 통째로 붙여 넣습니다.
3. **게시**를 누릅니다.

규칙을 등록하기 전에는 로그인해도 "서버가 요청을 거부했습니다"라고 나옵니다. 정상입니다.

### ③ 파일 올리기 (GitHub)
1. github.com/ekekfm/Homeboard → **Add file → Upload files**
2. ZIP을 푼 폴더 안의 파일과 폴더를 **전부** 끌어다 놓습니다. `js` 폴더와 숨김 폴더 `.github`가 빠지지 않게 확인하세요.
3. 아래 **Commit changes**를 누릅니다. 1~2분 뒤 https://ekekfm.github.io/Homeboard/ 에 반영됩니다.

### ④ 로그인 (PC 먼저)
1. PC에서 업무 보드를 열고 새로고침합니다. 화면 위쪽에 "동기화 꺼짐 · 로그인"이 보이면 새 버전입니다.
2. **홈 → PC·폰 동기화 → Google로 로그인**을 누릅니다.
3. "동기화됨"이 뜨면 이 기기의 기록(가계부·자산배분 제외)이 계정에 올라간 것입니다. **동기화 현황**에서 건수를 확인하세요.

### ⑤ 보안 점검, 그다음 가계부
1. 같은 카드에서 **보안 점검 실행**을 누릅니다. 막혀야 하는 요청 7가지를 서버에 직접 보내 보고, 전부 "통과"여야 합니다.
2. 모두 통과하면 **가계부·자산배분도 동기화** 버튼이 생깁니다. 이때 켜면 가계부가 계정에 올라갑니다.
3. 하나라도 "실패"면 가계부를 켜지 말고 화면을 캡처해 보내 주세요.

### ⑥ 폰 연결
1. 폰에서 업무 보드를 열고 같은 Google 계정으로 로그인합니다. 폰에만 있던 기록은 계정 기록과 합쳐집니다.
2. 폰에서도 가계부를 보려면 폰에서 보안 점검 후 가계부 동기화를 켭니다.
3. 홈 화면 아이콘 이름을 "업무 보드"로 바꾸려면, 기존 아이콘을 지우고 Safari(아이폰)나 Chrome(안드로이드)에서 다시 **홈 화면에 추가**합니다.

### 확인할 것
- [ ] PC에서 할 일을 하나 적고, 폰에 뜨기까지 몇 초 걸리는지
- [ ] 폰을 비행기 모드로 두고 3건 입력 → 비행기 모드 해제 → PC에 3건이 한 번씩만 보이는지
- [ ] 아이폰 홈 화면 앱에서 로그인이 되는지(안 되면 Safari에서 먼저 로그인해 보고 알려 주세요)
- [ ] 동기화 현황의 "이 기기"와 "계정" 건수가 같은지

## 동기화 규칙
- 기록 한 건씩 따로 저장합니다. 두 기기에서 서로 다른 기록을 고치면 둘 다 남습니다.
- 두 기기가 **같은 기록**을 거의 동시에 고치면, 먼저 서버에 도착한 내용이 남습니다. 늦은 쪽 내용은 지우지 않고 **충돌 기록**에 남기며, "되살리기"로 새 기록으로 되돌릴 수 있습니다.
- 지운 기록은 서버에 휴지통 표시로 남습니다(완전 삭제는 보안 규칙이 막음).
- 인터넷이 끊겨도 입력할 수 있고, 연결되면 자동으로 보냅니다.
- 처음 로그인하는 기기는 로그인 직전 기록을 따로 보관합니다(동기화 카드의 "내려받기").

## 무료 운영
- Firebase는 결제 수단 없이 Spark 플랜으로 씁니다. 하루 한도(읽기 5만, 쓰기 2만)를 넘으면 그날은 동기화만 멈추고 요금은 나오지 않습니다.
- Firebase 콘솔에서 **업그레이드(Blaze)** 버튼은 누르지 마세요.
- `js/firebase-config.js`의 값은 비밀키가 아니라 공개되어도 됩니다. 데이터는 보안 규칙이 지킵니다.
- 서비스 계정 키(비공개 키 JSON)는 이 저장소에 절대 올리지 않습니다.

## 알아둘 점
- 화면을 고친 뒤에는 `sw.js`의 `homeboard-v` 뒤 숫자를 올리면 설치된 앱이 새 화면으로 바뀝니다.
- Firebase 버전을 바꿀 때는 `js/firebase-backend.js`의 `V`와 `sw.js`의 `FIREBASE_V`를 같이 바꿉니다.
- 공개 저장소에 60일 동안 변경이 없으면 GitHub가 아침 뉴스 자동 실행을 끌 수 있습니다. 꺼지면 Actions 탭에서 다시 켭니다.
- 날씨는 Open-Meteo, 뉴스는 구글 뉴스 헤드라인(제목과 링크)을 씁니다.
